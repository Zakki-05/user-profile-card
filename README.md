# User Profile Cards Application

This project is a modern, responsive user profile management interface built with **React** and **Plain CSS**. It's designed to showcase clean UI/UX, state management, and component-based architecture.

## 🚀 Key Features
- **Dynamic Rendering**: Displays user data using React components and `.map()`.
- **Real-time Search**: Instant filtering of user cards by name.
- **Dark/Light Mode**: Seamless theme switching using React state and CSS variables.
- **Expandable Bios**: "Read More / Show Less" functionality for longer user bios.
- **Loading Skeleton**: Professional skeleton UI screens that appear while data is "loading".
- **Responsive Design**: Mobile-first layout using CSS Grid and Flexbox.
- **Interactive UI**: Hover effects, smooth transitions, and follow/message actions.

## 📁 Project Structure
- `src/App.jsx`: Main application controller and state manager.
- `src/components/UserCard.jsx`: Reusable card component for individual users.
- `src/components/SearchBar.jsx`: Search input component with real-time filtering.
- `src/data/users.js`: Centralized dummy data for user profiles.
- `src/style.css`: Modern design system with CSS variables and animations.

## 🛠️ How to Run Locally

1. **Install Dependencies**:
   Open your terminal in the project directory and run:
   ```bash
   npm install
   ```

2. **Start Development Server**:
   ```bash
   npm run dev
   ```

3. **Access the App**:
   Open your browser and navigate to the URL shown in your terminal (usually `http://localhost:5173`).

## 🎨 Design Inspiration
The design draws inspiration from modern professional networks like **LinkedIn** and creative portfolios like **Dribbble**, featuring:
- **Glassmorphism**: Subtle transparent backgrounds.
- **Soft Shadows**: Premium depth effects.
- **Outfit & Inter Fonts**: Clean, modern typography from Google Fonts.
- **Vibrant Gradients**: Used for accents and status indicators.
